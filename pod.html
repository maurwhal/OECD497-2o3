Point of departure (regression-based defined approach)

What is the point of departure (PoD), and how is it chosen?

The regression-based DA combines the equations below into one finite point of departure (PoD) for quantitative risk assessment. It is a "most likely" approximation of the LLNA EC3, or of the human DSA04, the concentration expected to sensitize 4% of people in a human repeat insult patch test. It is given as a % in a vehicle applied at 25 mg/cm² (like the LLNA) or as a dose per unit area in µg/cm², using the fixed factor 250. Appropriate safety factors for the use situation are applied to the PoD in risk assessment, which is outside the scope of the guideline and of this page.

Which equations. At least two tests (two key events) are required. With all three tests, the DA uses EQ5 and EQ5e. With two tests it uses the matching pair: EQ1/EQ1d (KeratinoSens + kDPRA), EQ4/EQ4d (h-CLAT + kDPRA), or EQ6/EQ6d (KeratinoSens + h-CLAT). In each case the lower of the LLNA-trained value and the potency-value-trained value is the PoD (the more conservative one). Equations 5d and 7, shown below from the ESM3 workbook, are not part of the DA. Where a test was run several times, the geometric mean of the individual values is used as the input. If a result is inconclusive or outside the assay's applicability domain (for example, an insoluble test chemical), tick the box under that assay: the calculation still runs, but the PoD is labeled exploratory and a valid-tests-only PoD is shown, since the DA needs at least two valid tests.

Source: draft OECD TG 497, Part 3 "Regression-based defined approach for derivation of a point of departure" (a public-consultation draft, so wording may change).

Results — models trained on LLNA data (EC3)

pED = model's linear predictor; EC3% = MW / 10^pED; DSA (dose per surface area) = EC3% × 250, in µg/cm².

Results — models trained on extended Potency Values (PV)

Per ESM3's own guidance: a conservative assessment may take the lower PoD of the LLNA- and PV-trained models, unless there's a mechanistic reason to prefer one (e.g. a strongly cytotoxic chemical with weak alerts/reactivity — prefer the PV-trained model there to avoid a cytotoxicity-driven bias).

Rules applied (draft OECD TG 497 Part 3, with TG 442D): the DA combines multiple tests of one assay by the geometric mean of the individual values. Every run with a calculated value counts, whatever its call: the default 4000 µM is for when no luciferase induction (EC1.5) or no cytotoxicity (IC50) was observed at all, not for a run that was merely rated negative or borderline (the model was trained with borderline data, and the ESM3 workbook applies the default only to "no induction above threshold"). A run's call only sets the overall rating (majority of the runs, 2 of 3), and two runs that disagree call for a third run (TG 442D). At least two independent runs are expected. Geometric mean = the n-th root of the product of n values. This is for the PoD inputs only, separate from the arithmetic averages used for house-style cells.

About the CompTox lookup

What it is. The EPA CompTox Chemicals Dashboard is a public database of chemical identifiers and properties. EPA's Computational Toxicology and Exposure (CTX) APIs let a program pull that data automatically instead of looking each chemical up by hand. More about the CTX APIs (EPA)

What the button fills in. Molecular weight (EPA's average mass) and vapor pressure, for the CAS # you entered. Both feed the regression equations above.

How vapor pressure is chosen. If EPA has experimental records, the value used is their median. If it has none, the value used is the median of EPA's predicted (model) values, and the page says PREDICTED. EPA reports mmHg; the page converts to Pa (1 mmHg = 133.322 Pa). Every record, its source, and its temperature (when EPA gives one) are listed under "CompTox sources" so you can judge them yourself.

How it works. This page sends the CAS # and the password to a small server (a Cloudflare Worker). The server adds an EPA API key, asks EPA, and sends the answer back. A server is needed because EPA's replies carry a duplicated browser-permission header that browsers refuse to read directly. The EPA key stays on that server and is never in this page's code.

Why a password. The EPA key is one person's free key, so the password keeps other visitors from using it up. It is remembered only until you close the tab.

Check before relying on it. These are values from public databases, not a substitute for your own data. Predicted values are model estimates, records can disagree, and some have no stated temperature. If the lookup is unavailable, look the chemical up on the CompTox Dashboard yourself and type the values in, choosing the unit in the vapor pressure box.
